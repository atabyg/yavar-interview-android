- وضعیت انطباق با پرامپت‌های مرجع (PASS/FAIL/NOT TESTED): `docs/CONFORMANCE_MATRIX.md`؛ برنامهٔ اجرا و کارهای باز: `docs/EXECUTION_PLAN.md`.
