# چک‌لیست آزمون دستگاه واقعی

وضعیت فعلی: هیچ آزمون فیزیکی در این کار اجرا نشده است.

- [ ] نصب پاک روی Redmi 8 یا دستگاه ARM64 پشتیبانی‌شده
- [ ] ارتقا روی نسخهٔ قبلی با همان applicationId و امضای پایدار، بدون حذف داده
- [ ] نصب با امضای متفاوت: نمایش پیام روشن و دستور پشتیبان‌گیری پیش از هر اقدام مخرب
- [ ] ضبط ۱۵/۳۰/۶۰ دقیقه و ذخیرهٔ پایدار صوت
- [ ] قطع تماس/هدست، رفتن به پس‌زمینه، kill و راه‌اندازی مجدد
- [ ] تبدیل آفلاین فارسی بدون درخواست شبکه
- [ ] حالت آنلاین: قطع اینترنت، 401/403، 429، 5xx، timeout، پاسخ خالی و پاسخ خراب
- [ ] حفظ صف و داده پس از هر خطا
- [ ] import فایل TXT/MD/DOCX و متن سادهٔ AI خارجی بدون رمزگذاری
- [ ] backup/restore روی نصب تازه با بررسی hash و پیش‌نمایش
- [ ] چاپ/خروجی PDF و Excel پس از دریافت PDF مرجع صحیح
- [ ] بررسی RAM، گرما، باتری، زمان تبدیل و کیفیت گفتار در محیط شلوغ
- [ ] بررسی ABI و تراز ELF برای صفحات ۱۶KB روی Android 15+
