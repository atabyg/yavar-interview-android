# ماتریس انطباق با «سند مادر» و «الحاقیه» — وضعیت واقعی

وضعیت‌ها فقط سه مقدارند: **PASS** (آزمون واقعاً اجرا و موفق شده)، **FAIL** (نقص شناخته‌شده و رفع‌نشده)، **NOT TESTED** (اجرا نشده یا شاهد کافی نیست).
«PASS» در این جدول یعنی آزمون خودکار Node (و در صورت ذکر، CI)؛ **هیچ‌یک از موارد روی گوشی واقعی آزموده نشده است**.
آخرین به‌روزرسانی: شاخهٔ `feature/version-13` پس از رفع «ندارد» در تحلیل درون‌برنامه‌ای، رابط بازبینی و تأیید حریم خصوصی. CI آخرین commit بررسی‌شده (`c478e99e`): آزمون‌های Node + build وب + ساخت و راستی‌آزمایی APK آزمایشی هر دو اجرا موفق بود (runهای 40010011779 و 40010017453).
