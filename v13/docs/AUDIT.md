# ممیزی نسخهٔ ۱۳ — وضعیت اولیه

تاریخ ممیزی: ۲۰۲۶-۱۰-۲۰  
مخزن: `atabyg/yavar-interview-android`  
شاخهٔ پایهٔ مشاهده‌شده: `feature/version-12-noisy-persian-transcription`  
شاخهٔ کاری: `feature/version-13`

## خلاصهٔ وضعیت
این سند ممیزی اولیه است؛ به‌معنای تکمیل WPها یا تأیید کیفیت محصول نیست. فقط مواردی که با GitHub API و فایل‌های موجود قابل مشاهده بودند به‌عنوان تأییدشده ثبت شده‌اند.

## تأییدشده از مخزن
1. مخزن عمومی است و دسترسی push برای حساب متصل گزارش شده است.
2. شاخهٔ `feature/version-12-noisy-persian-transcription` وجود داشت. در جست‌وجوی اولیه شاخهٔ `feature/version-13` وجود نداشت؛ سپس شاخهٔ مستقل از v12 ایجاد شد.
3. `v12/capacitor.config.json` شناسهٔ `com.yavarshahrha.interview` را دارد. این شناسه نباید تغییر کند.
4. پروژه بر Capacitor 6، Vite و React 18 استوار است. `@capacitor/app` در `v12/package.json` موجود نیست.
5. `v12/package.json` دارای اسکریپت تستی است که `node --test tests/*.test.js` و سپس build وب را اجرا می‌کند.
6. `v12/patch-android.sh` مقدار نسخهٔ ۹ و `v12/patch-v12.sh` مقدار نسخهٔ ۱۲ را می‌نویسند؛ این دو مرحله در خط لولهٔ موجود، خطر تنظیم چندبارهٔ نسخه ایجاد می‌کنند.
7. `v12/patch-v12.sh` در صورت نبود چهار Secret امضا، به امضای debug پیش‌فرض برمی‌گردد. در این حالت نصب روی نسخهٔ قبلی با تضمین سازگاری امضا همراه نیست.
8. Workflow نسخهٔ ۱۲ از `ubuntu-latest` و `npm install` استفاده می‌کند و در سطح مخزن `package-lock.json` تأیید نشده است.
9. `v12/native/CMakeLists.txt` گزینه‌های `GGML_NATIVE=OFF`، `GGML_OPENMP=OFF` و `GGML_CPU_ALL_VARIANTS=OFF` را تنظیم می‌کند؛ بنابراین بهینه‌سازی‌های اختصاصی CPU هنوز اثبات نشده‌اند.
10. `v12/src/recorder.js` از `MediaRecorder` در WebView استفاده می‌کند. ضبط بومی PCM16 و مسیر Foreground Service در این ممیزی تأیید نشده‌اند.

## مرجع PDF فرم‌ها — مانع قطعی برای WPهای وابسته
پرامپت مرجع واحد را PDF بیست‌وپنج‌صفحه‌ای با SHA-256 زیر معرفی می‌کند:

`7aba32566e611d99fe4a705b6534a510711405ec22f42f8ab5b8f2b937cb3183`

در کتابخانه، فایل قابل‌دسترسی `bsth_frm_hy_F00_t_F08_eslahat_emal_shode (1).pdf` بررسی شد:
- SHA-256 محاسبه‌شده: `aefd9bbd3999b511acc13417b0ac2c6109c82d35dbafb45264f63140b7242da9`
- تعداد صفحه: ۲۲
- عنوان PDF: «بسته فرم‌های ارجاع شغلی یاورشهرها ۱۴۰۵ - ویرایش ۵ اصلاح‌شده»
- AcroForm: ندارد

هش و تعداد صفحه با مرجع پرامپت یکسان نیست. بنابراین فایل موجود را نمی‌توان به‌جای PDF مرجع پذیرفت. مطابق دستور، طراحی/کدگذاری فرم و WPهای وابسته به مرجع (از جمله WP2، WP5، WP8 و WP17) متوقف می‌مانند تا PDF صحیح فراهم و هش آن محاسبه شود. محتوای فرم‌ها از فایل ۲۲صفحه‌ای استخراج یا حدس زده نمی‌شود.

## موارد مسدود یا انجام‌نشده
- PDF دقیق مرجع ۲۵صفحه‌ای و تأیید هش.
- بازسازی وفادار F00 تا F09 و نگاشت کامل کدها.
- WP0 کامل: lockfile قابل‌تکرار، NDK پین‌شده، بررسی ELF/۱۶KB و کنترل نسخهٔ یکتا هنوز تأیید نشده‌اند.
- WP15 کامل: مسیر واقعی backup/restore، اعتبارسنجی هش، merge و آزمون round-trip هنوز پیاده‌سازی و آزموده نشده‌اند.
- WP1/WP7: مهاجرت امن داده، حذف داده فقط با تأیید، خروج امن و بازیابی پس از kill هنوز به‌طور کامل آزموده نشده‌اند.
- WP3/WP4: گفتار آفلاین/آنلاین، VAD، قطعه‌بندی، لغو، سرویس پیش‌زمینه و آزمون کیفیت WER/CER اجرا نشده‌اند.
- آزمون‌های واقعی روی Redmi 8 یا دستگاه فیزیکی دیگر انجام نشده‌اند.
- CI نسخهٔ ۱۳ هنوز باید اجرا و نتیجهٔ واقعی ثبت شود؛ ایجاد workflow به‌معنای build موفق نیست.

## آزمون‌های لازم پیش از انتشار
1. CI روی Ubuntu 24.04: تست‌های Node، build وب، ساخت APK، بررسی package/applicationId/versionCode، امضا و آرتیفکت.
2. آزمون migration و round-trip با دادهٔ ساختگی، بدون حذف یا بازنویسی رکوردهای قبلی.
3. آزمون‌های خطای شبکه، سهمیه، پاسخ خالی/خراب و حفظ صف.
4. آزمون آفلاین واقعی بدون تماس شبکه و بدون fallback سیستمی پنهان.
5. آزمون فایل صوتی طولانی، WAV با chunkهای اضافی، وقفه، kill/restart و بازیابی.
6. آزمون PDF/Excel و کنترل بصری پس از دریافت مرجع صحیح.
7. نصب ارتقایی با همان امضای پایدار و آزمون روی دستگاه واقعی.

## صداقت گزارش
هیچ نتیجه‌ای دربارهٔ نصب روی گوشی، دقت گفتار، عملکرد در نویز، مصرف RAM/باتری یا سازگاری ۱۶KB بدون اجرای آزمون واقعی ادعا نمی‌شود.
