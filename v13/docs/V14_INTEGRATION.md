# نسخهٔ ۱۴ — ادغام v13 و Face ID

## این نسخه چیست
نسخهٔ ۱۴ ترکیب دو شاخه است:
- `feature/version-13` (آخرین وضعیت): قرارداد JSON `YAVAR_CASE_RESULT` v1 با اعتبارسنجی و تطبیق شاهد، ورود نتیجهٔ آفلاین با خلاصهٔ تغییرات و حفظ نسخهٔ قبلی، خروجی پیش‌فرض JSON برای هوش مصنوعی بیرونی (بدون نام مددجو)، نمایش وضعیت/پیشنهاد/تناقض در جزئیات، تأیید حریم خصوصی پیش از ارسال، رفع «ندارد» در تحلیل درون‌برنامه‌ای، تحمل بخش صوتی بی‌گفتار.
- `feature/version-13-face-id`: شناسایی چهرهٔ کاملاً آفلاین (YuNet + SFace روی ONNX Runtime Web)، ذخیرهٔ رمزگذاری‌شدهٔ قالب‌ها، اسکن در صفحهٔ ضبط برای یافتن پرونده/نام.

ادغام با PR #17 انجام شد (merge commit `a2fddb93`)؛ git هیچ تعارضی گزارش نکرد چون دو شاخه فایل مشترک نداشتند.

- `patch-v13.sh`: `versionCode 14`، `versionName 14.0.0` (با assert).

- شاخه‌های `feature/version-13` و `feature/version-13-face-id` دست‌نخورده‌اند.

## فعال‌سازی ساخت APK (یک‌بار، توسط شما)
ابزار من نمی‌تواند در `.github/workflows/` بنویسد؛ فایل آماده در ریشهٔ مخزن است:
1. در GitHub شاخهٔ `feature/version-14` را باز کنید و فایل `build-apk-v14.yml` (ریشه) را باز کنید.
2. آیکن مداد → در کادر نام فایل، ابتدای متن (قبل از `build-apk-v14.yml`) را کلیک کنید و `.github/workflows/` را تایپ کنید.
3. Commit مستقیم روی `feature/version-14`. ساخت خودکار شروع می‌شود (آزمون‌های Node + build وب + مدل‌های چهره + APK + راستی‌آزمایی).
4. نتیجه (خلاصهٔ لاگ) در شاخهٔ `ci-status-v14`، فایل `v14-latest.md` نوشته می‌شود؛ APK در Artifacts اجرا با نام `yavar-interview-v14-apk`.

## نکات مهم پیش از استفادهٔ میدانی
- **زیست‌سنجی داده‌ای بسیار حساس است.** مطابق `FACE_ID_PROGRESS.md` هنوز باز است: حذف قالب چهرهٔ یک پرونده (فقط «حذف همهٔ داده‌های چهره» هست و حذف مصاحبه، قالب چهره را پاک نمی‌کند)، تشخیص زنده‌بودن (عکس چاپی یا صفحه‌نمایش می‌تواند اسکن را فریب دهد)، چاپ QR در PDF/DOCX. قبل از ثبت چهرهٔ هر مددجو، رضایت آگاهانهٔ او را بگیرید؛ نتیجهٔ شناسایی چهره را فقط کمکی بدانید، نه مبنای تصمیم.
- فایل‌های خروجی برای هوش مصنوعی بیرونی (قرارداد JSON) نام مددجو و داده/قالب چهره ندارند؛ صدای ضبط‌شده همچنان قابل شناسایی است و پیش از ارسال تأیید گرفته می‌شود.
- **ارتقا**: بدون کلید امضای ثابت، APK جدید روی نصب قبلی نصب نمی‌شود (باید برنامهٔ قبلی حذف شود؛ پیش از آن خروجی داده بگیرید). برای رفع، secretهای `YAVAR_KEYSTORE_B64`، `YAVAR_STORE_PASSWORD`، `YAVAR_KEY_ALIAS`، `YAVAR_KEY_PASSWORD` را در Actions secrets بگذارید.
- حجم APK حدود ۸۰ مگابایت است (مدل‌ها و ONNX Runtime داخل APK).
