# نسخهٔ ۱۴ — ادغام v13 و Face ID

## این نسخه چیست
نسخهٔ ۱۴ ترکیب دو شاخه است:
- `feature/version-13` (آخرین وضعیت): قرارداد JSON `YAVAR_CASE_RESULT` v1 با اعتبارسنجی و تطبیق شاهد، ورود نتیجهٔ آفلاین با خلاصهٔ تغییرات و حفظ نسخهٔ قبلی، خروجی پیش‌فرض JSON برای هوش مصنوعی بیرونی (بدون نام مددجو)، نمایش وضعیت/پیشنهاد/تناقض در جزئیات، تأیید حریم خصوصی پیش از ارسال، رفع «ندارد» در تحلیل درون‌برنامه‌ای، تحمل بخش صوتی بی‌گفتار.
- `feature/version-13-face-id`: شناسایی چهرهٔ کاملاً آفلاین (YuNet + SFace روی ONNX Runtime Web)، ذخیرهٔ رمزگذاری‌شدهٔ قالب‌ها، اسکن در صفحهٔ ضبط برای یافتن پرونده/نام.

ادغام با PR #17 انجام شد (merge commit `a2fddb93`)؛ git هیچ تعارضی گزارش نکرد چون دو شاخه فایل مشترک نداشتند.

## نکات مهم پیش از استفادهٔ میدانی
- **زیست‌سنجی داده‌ای بسیار حساس است.** طبق `FACE_ID_PROGRESS.md` هنوز باز است: حذف قالب چهرهٔ یک پرونده (فقط «حذف همهٔ داده‌های چهره» هست و حذف مصاحبه قالب چهره را پاک نمی‌کند)، تشخیص زنده‌بودن (عکس چاپی یا صفحه‌نمایش می‌تواند اسکن را فریب دهد)، چاپ QR در PDF/DOCX. در رابط اسکن کادر رضایت هم نیست. پیش از ثبت چهرهٔ هر مددجو رضایت آگاهانهٔ او را بگیرید و نتیجهٔ چهره را فقط کمکی بدانید، نه مبنای تصمیم.
- فایل‌های خروجی برای هوش مصنوعی بیرونی (قرارداد JSON) نام مددجو و داده/قالب چهره ندارند؛ صدای ضبط‌شده همچنان قابل شناسایی است و پیش از ارسال تأیید گرفته می‌شود.
- **ارتقا**: بدون کلید امضای ثابت، APK جدید روی نصب قبلی نصب نمی‌شود (باید برنامهٔ قبلی حذف شود؛ پیش از آن خروجی داده بگیرید). برای رفع، secretهای `YAVAR_KEYSTORE_B64`، `YAVAR_STORE_PASSWORD`، `YAVAR_KEY_ALIAS`، `YAVAR_KEY_PASSWORD` را در Actions secrets بگذارید.
