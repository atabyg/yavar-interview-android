# یاور مصاحبه – نسخهٔ ۸

## ساخت APK
Workflow ساخت در مسیر فعال GitHub Actions قرار دارد: `.github/workflows/build-apk-v8.yml`.
با هر push شامل تغییرات `v8/**` یا اجرای دستی Workflow، ساخت APK، بررسی وجود فایل و بارگذاری artifact انجام می‌شود؛ در صورت موفقیت، APK در بخش Releases نیز منتشر می‌شود.

## اجرای محلی
از داخل پوشهٔ `v8`:
```sh
cat assets/logo/p?.txt | base64 -d > src/assets/logo.png
npm install
npm run build
```

## نکات مهم
- ضبط‌ها و آرشیو به‌صورت محلی در IndexedDB نگهداری می‌شوند؛ از خروجی/پشتیبان‌گیری منظم استفاده کنید.
- کلید API در حافظهٔ محلی دستگاه ذخیره می‌شود و رمزگذاری اختصاصی ندارد. دستگاه را ایمن نگه دارید و کلید را با دیگران به اشتراک نگذارید.
- پردازش خودکار به‌طور پیش‌فرض خاموش است. برای ارسال صوت/متن به OpenAI، پردازش را آگاهانه از صفحهٔ مصاحبه آغاز کنید یا گزینهٔ خودکار را فعال کنید.
- ساخت موفق APK به‌تنهایی جایگزین آزمون نصب، ضبط طولانی، بازیابی، PDF/Excel و سازگاری روی دستگاه‌های واقعی نیست.
