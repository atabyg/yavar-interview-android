# یاور مصاحبه — نسخهٔ ۹

نسخهٔ ۹ بر پایهٔ کد نسخهٔ ۸ ساخته شده است. پوشهٔ `v8` بدون تغییر باقی می‌ماند و نسخهٔ جدید در `v9/` نگهداری می‌شود. پایگاه داده و شناسهٔ برنامه حفظ شده‌اند تا در صورت نصب به‌روزرسانی، آرشیو قبلی قابل دسترسی بماند.

## امکانات نسخهٔ ۹
- تشخیص گفتار زنده با ترجیح آفلاین اندروید و نمایش متن موقت/نهایی در صفحهٔ ضبط.
- انتخاب جداگانهٔ سرویس تحلیل متن: Groq، Gemini، Mistral یا OpenAI.
- انتخاب جداگانهٔ سرویس تبدیل صوت: روی گوشی، Groq Whisper یا OpenAI Transcription.
- سه پیش‌تنظیم پرسش: فوری، ۱۲ سؤال حیاتی و پرسش‌نامهٔ کامل.
- گزارش‌ها و تاریخ پرونده با تقویم شمسی فارسی.
- اتصال API فقط با کلیدی که کاربر خودش داخل تنظیمات وارد می‌کند؛ هیچ کلیدی در کد قرار داده نشده است.

## نکات مهم دربارهٔ آفلاین و نویز
تشخیص گفتار با موتور نصب‌شده روی گوشی انجام می‌شود. در Android 12 و بالاتر، اپ در صورت پشتیبانی سیستم از recognizer محلی استفاده می‌کند. در نسخه‌های قدیمی‌تر، اندروید فقط یک ترجیح آفلاین ارائه می‌دهد و ممکن است موتور سازنده آن را نادیده بگیرد. وجود بستهٔ زبان فارسی آفلاین در دستگاه باید تأیید شود. هیچ راهکاری نمی‌تواند متن کاملاً دقیق را با هر مقدار نویز یا مکالمهٔ هم‌زمان تضمین کند؛ متن را پیش از استفادهٔ رسمی بازبینی کنید. اگر موتور فارسی آفلاین روی گوشی فعال نبود، تبدیل صوت ابری یک انتخاب جداگانه است و به اینترنت و کلید API نیاز دارد.

## کلیدها و حریم خصوصی
کلیدها در حافظهٔ محلی برنامه ذخیره می‌شوند و در این نسخه رمزگذاری اختصاصی ندارند. کلید را در مخزن، تصویر عمومی یا پیام عمومی قرار ندهید. فعال‌کردن تحلیل خودکار، متن مصاحبه را به سرویس تحلیل منتخب می‌فرستد؛ سرویس‌های ابری ممکن است سیاست نگهداری و شرایط منطقه‌ای متفاوت داشته باشند. برای اطلاعات حساس، رضایت و قواعد سازمان خود را رعایت کنید. سهمیهٔ رایگان سرویس‌ها محدود و متغیر است و تضمین‌شده نیست.

## ساخت APK
GitHub Actions workflow فعال: `.github/workflows/build-apk-v9.yml`

با هر push شامل تغییرات `v9/**` یا اجرای دستی workflow، ساخت APK آغاز می‌شود. پس از پایان موفق، فایل `yavar-interview-v9.apk` در بخش Artifacts همان اجرای Actions قرار می‌گیرد.

اجرای محلی، از داخل پوشهٔ `v9`:
```sh
cat assets/logo/p?.txt | base64 -d > src/assets/logo.png
npm install
npm test
```

موفقیت build به‌تنهایی جایگزین آزمون عملی نصب روی گوشی، تشخیص فارسی آفلاین، ضبط طولانی، بررسی متن و آزمون سرویس‌های API نیست.
