# یاور مصاحبه — نسخهٔ ۱۱

شاخهٔ آماده‌سازی: `feature/version-11-stable`؛ شاخهٔ مبنا: `feature/version-11-daily-archive`.
شناسهٔ بستهٔ اندروید حفظ شده تا به‌روزرسانی نسخهٔ سازگار ممکن بماند. نسخهٔ APK باید `versionName 11.0.0` و `versionCode 11` داشته باشد.

## اصلاحات نسخهٔ ۱۱

- **تشخیص بهتر خطای تبدیل آفلاین:** صفحهٔ تنظیمات حالا کتابخانهٔ بومی Whisper/JNI را هم هنگام آزمون آمادگی بارگذاری می‌کند و خطای ABI یا کتابخانه را با جزئیات نشان می‌دهد، نه اینکه صرفاً «مدل آماده نیست» اعلام کند. مدل چندزبانهٔ Whisper همچنان داخل APK است و برای استفادهٔ اولیه دانلود جداگانه لازم نیست.
- **هوش مصنوعی با سهمیهٔ محدود:** گزینه‌های تحلیل به Groq GPT-OSS 20B/120B و Gemini Flash-Lite محدود شده‌اند؛ مدل بازنشستهٔ Llama 3.3 70B، انتخاب‌های API معمولاً پولی و تبدیل صوت OpenAI از فهرست تنظیمات حذف شده‌اند. تبدیل پیش‌فرض کاملاً آفلاین است. سهمیهٔ رایگان تضمینی یا نامحدود نیست؛ اگر برای حساب سرویس صورتحساب فعال است، رایگان‌بودن یک مدل به‌تنهایی سقف هزینهٔ کلی حساب را تضمین نمی‌کند.
- **شمارهٔ پرونده:** شمارهٔ تصادفی شش‌رقمی از میان شماره‌های ذخیره‌شده و پرونده‌های موجود انتخاب می‌شود؛ برای جلسهٔ بعدی همان مددجو، شمارهٔ پروندهٔ قبلی را وارد کنید.
- **برچسب سمت:** به «عنوان شغلی یا مسئولیت فعلی مددجو» روشن‌تر شد.
- **آرشیو روزانهٔ متنی:** تاریخ و گروه‌بندی شمسی بر پایهٔ زمان تهران است. با متنی‌شدن مصاحبه‌ها، فایل‌های TXT ساختاریافته با شناسهٔ روز و پرونده در حافظهٔ خصوصی برنامه به‌روز می‌شوند؛ می‌توان هر گفت‌وگو را از فایل روز حذف/دوباره اضافه کرد یا فایل و پرامپت را خروجی گرفت. حذف از فایل روزانه متن اصلی پرونده یا صوت را پاک نمی‌کند.
- **آزمون‌ها و ساخت:** CI آزمون‌های تاریخ شمسی، شمارهٔ پرونده و قالب فایل روزانه را پیش از build اجرا می‌کند و بعد نسخهٔ داخلی APK، امضا و خروجی را بررسی می‌کند.

## ارائه‌دهندگان رایگان محدود برای تحلیل متن

در شاخهٔ توسعهٔ ارائه‌دهندگان نسخهٔ ۱۱، بخش تحلیل شش انتخاب دارد:

- **Groq** — مدل‌های GPT-OSS 20B و 120B با سهمیهٔ رایگان محدود: [ساخت کلید](https://console.groq.com/keys)
- **Google Gemini** — مدل‌های Flash دارای سطح رایگان محدود: [ساخت کلید در AI Studio](https://aistudio.google.com/apikey)
- **Cerebras** — مدل‌های فهرست‌شدهٔ قابل‌دسترسی با API سازگار با OpenAI: [ورود به پنل و ساخت کلید](https://cloud.cerebras.ai/platform)
- **OpenRouter Free** — مدل openrouter/free به‌طور خودکار از بین مدل‌های رایگانِ دردسترس انتخاب می‌کند؛ کاربر نیازی به تنظیم دستی مدل ندارد: [ساخت کلید](https://openrouter.ai/settings/keys)
- **Mistral AI** — حالت رایگان Studio با محدودیت درخواست و توکن و بدون نیاز به کارت بانکی: [ساخت کلید](https://console.mistral.ai/api-keys)
- **Hugging Face Inference Providers** — API سازگار با OpenAI با مدل openai/gpt-oss-120b. حساب رایگان اعتبار ماهانهٔ آزمایشی بسیار محدود (در حال حاضر ۰٫۱۰ دلار، قابل تغییر) دارد؛ پس از اتمام اعتبار باید درخواست ناموفق شود مگر اینکه کاربر اعتبار اضافه بخرد: [ساخت توکن](https://huggingface.co/settings/tokens)

برای راه‌اندازی، در تنظیمات سرویس را انتخاب کنید، لینک رسمی ساخت کلید/توکن را باز کنید، کلید شخصی را در برنامه وارد کرده و «آزمون اتصال و ذخیره» را بزنید. برای Hugging Face توکنی بسازید که اجازهٔ «Make calls to Inference Providers» داشته باشد. برنامه کلیدها را داخل مخزن یا APK قرار نمی‌دهد؛ هر کاربر کلید خودش را وارد می‌کند. سرویس‌ها بدون حساب و کلید شخصی، API عمومی تضمین‌شده‌ای ارائه نمی‌کنند و تعبیهٔ یک کلید مشترک در برنامهٔ عمومی ناامن است.

سهمیه، مدل قابل‌دسترسی و شرایط استفاده می‌تواند بر اساس زمان، منطقه، حساب و سیاست سرویس تغییر کند؛ خطای محدودیت رایگان به معنی خرابی خود اپلیکیشن نیست. اعتبار رایگان Hugging Face کوچک و محدود است و رایگان نامحدود محسوب نمی‌شود. در حالت OpenRouter یا Hugging Face، متن ممکن است برای پردازش به یکی از ارائه‌دهندگان مدل‌های زیرمجموعه فرستاده شود. متن مصاحبه حاوی اطلاعات شخصی است؛ پیش از ارسال ابری، مجوز لازم و سیاست محرمانگی سازمان را رعایت کنید و اطلاعات هویتی غیرضروری را از متن حذف کنید. حالت تبدیل گفتار پیش‌فرض همچنان کاملاً آفلاین است.

## نصب و به‌روزرسانی

Android امضای APK را کنترل می‌کند و اجازهٔ نصب روی اپلیکیشن دارای امضای متفاوت را نمی‌دهد. اگر نصب قدیمی با کلید debug موقت ساخته شده باشد، ممکن است فقط برای ارتقای اول ناچار شوید نسخهٔ قبلی را حذف کنید؛ نسخه‌های بعدی با امضای ثابت یکسان به‌روزرسانی می‌شوند. پیش از حذف نسخهٔ قبلی، از آرشیوهای ضروری خروجی بگیرید.

**امنیت امضای APK:** ساخت از کلید ثابت فقط با اسرار مخزن انجام می‌شود: `YAVAR_KEYSTORE_B64`، `YAVAR_STORE_PASSWORD`، `YAVAR_KEY_ALIAS` و `YAVAR_KEY_PASSWORD`. در نبود این اسرار، CI از امضای debug استفاده می‌کند و سازگاری به‌روزرسانی تضمین نمی‌شود. کلیدهای قدیمی پیش‌تر در تاریخچهٔ عمومی بوده‌اند؛ برای توزیع حساس، کلید را بچرخانید و وضعیت به‌روزرسانی نصب‌های قدیمی را بررسی کنید.

موفقیت ساخت به‌تنهایی آزمون روی گوشی واقعی نیست. برای پذیرش نسخه، باید نصب/ارتقا، نمایش وضعیت مدل در تنظیمات، تبدیل یک نمونهٔ صوت فارسی در حالت پرواز، ضبط طولانی و آرشیو روزانه در گوشی هدف نیز بررسی شود.
