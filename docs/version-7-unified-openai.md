# نسخه ۷ یاور — هوش مصنوعی یکپارچه OpenAI

## راه‌اندازی
1. در تنظیمات، کلید API حساب OpenAI را وارد کنید.
2. دکمه «آزمایش اتصال OpenAI (بدون پرونده)» را بزنید.
3. کلید فقط در حافظه اجرای برنامه نگهداری می‌شود و با قفل دستی یا خودکار پاک می‌شود؛ در پرونده یا localStorage ذخیره نمی‌شود.
4. برای ارسال متن یا صوت یک پرونده به سرویس ابری، رضایت مستقل همان پرونده لازم است.

## معماری
- همه قابلیت‌های ابری از OpenAI استفاده می‌کنند: تبدیل صوت به متن با `gpt-4o-mini-transcribe` و تحلیل متن/نقش گوینده/استخراج مشخصات با `gpt-4o-mini`.
- هر دو مسیر از یک کلید API OpenAI استفاده می‌کنند؛ هیچ fallback پنهانی به DeepSeek، Groq یا سرویس دیگری وجود ندارد.
- مدل رونویسی با خروجی JSON لزوماً timestamp مجزا برای همه جمله‌ها برنمی‌گرداند؛ در صورت نبود segment، زمان شروع پیش‌فرض استفاده می‌شود. نقش گوینده پیشنهادی است و باید انسانی بازبینی شود.
- آزمایش اتصال فقط یک پیام ثابت ارسال می‌کند و اطلاعات پرونده را نمی‌فرستد.

## حریم خصوصی و محدودیت‌ها
- صوت و متن پرونده فقط پس از رضایت مستقل همان پرونده ارسال می‌شود. پیش از ارسال، متن را از اطلاعات شناسایی‌کننده غیرضروری پاک کنید.
- کلید در حافظه کلاینت کاملاً محرمانه نیست؛ کلید سازمانی مشترک را داخل APK عمومی قرار ندهید.
- مدل فقط پیشنهاد می‌دهد و امتیاز رسمی یا تصمیم کارشناسی را خودکار تغییر نمی‌دهد.
- به اینترنت، کلید معتبر و اعتبار/سهمیه API نیاز است؛ تعرفه، محدودیت فایل و دسترسی شبکه تابع حساب و سیاست فعلی سرویس است.

## ساخت و آزمون
گردش‌کار GitHub Actions، منبع برنامه را به فضای Capacitor کپی و `npm run build` را اجرا می‌کند. موفقیت این بررسی فقط ساخت bundle وب را تأیید می‌کند، نه ساخت APK نهایی یا آزمون روی گوشی.
