# سازگاری دستگاه — نسخه ۲

- حداقل نسخه بومی در اسکریپت ساخت: Android 6.0 / API 23 تا احراز زیستی AndroidX قابل ارزیابی باشد.
- هدف آزمون پیشنهادی: Android 8.1 یا بالاتر، شامل Xiaomi Redmi 8 و یک دستگاه Samsung هم‌رده.
- حسگر اثرانگشت و اثرانگشت ثبت‌شده توسط سیستم‌عامل لازم است؛ در صورت نبود یا لغو احراز زیستی، ورود با PIN باقی می‌ماند.
- استفاده از BiometricPrompt در این شاخه هنوز روی دستگاه واقعی تأیید نشده است.
- حداقل دسترسی‌های موردنیاز ساخت فعلی: اینترنت فقط برای درخواست دستی AI، و میکروفون/تنظیم صدا برای ضبطی که کاربر صریحاً آغاز می‌کند. UI تشخیص گفتار ابری مرورگر غیرفعال است.
- PDF با اقدام صریح کاربر به‌صورت فایل بومی تولید می‌شود؛ کاربر پوشه عمومی را از طریق سندگزین اندروید انتخاب می‌کند یا منوی share را باز می‌کند.
- APK مرحله CI از نوع debug است و نباید به‌عنوان نسخه انتشار امضاشده فرض شود.
- داده محلی در این پیش‌نویس هنوز در حالت سکون رمزنگاری نشده است. تا پیاده‌سازی Android Keystore/رمزنگاری و آزمون مهاجرت، فقط از داده ساختگی استفاده شود.
