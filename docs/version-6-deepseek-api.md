# نسخه ۶ یاور — اتصال DeepSeek

## راه‌اندازی
1. در تنظیمات، ارائه‌دهنده «DeepSeek» را انتخاب کنید.
2. کلید API خودتان را وارد کنید و «آزمایش اتصال DeepSeek (بدون پرونده)» را بزنید.
3. پس از موفقیت، کلید فقط در حافظه همین اجرای برنامه نگه داشته می‌شود؛ با قفل دستی یا قفل خودکار پاک می‌شود.
4. برای تحلیل متن هر پرونده، رضایت ارسال ابری همان پرونده را جداگانه فعال کنید و در صفحه سؤال‌ها درخواست تحلیل را اجرا کنید.

## حریم خصوصی و محدودیت‌ها
- آزمایش اتصال فقط یک پیام آزمایشی ثابت می‌فرستد و متن/مشخصات پرونده را ارسال نمی‌کند.
- تحلیل پرونده به سرویس رسمی `https://api.deepseek.com/chat/completions` متصل می‌شود و به اینترنت و اعتبار/سهمیه API نیاز دارد.
- کلید در localStorage، پرونده، خروجی‌ها یا مخزن نوشته نمی‌شود. چون برنامه مستقیماً از گوشی به API متصل است، کلید واردشده در حافظه کلاینت را نمی‌توان در برابر کاربر دستگاه کاملاً محرمانه دانست؛ کلید سازمانی یا مشترک را در APK عمومی قرار ندهید.
- متن پرونده فقط پس از رضایت ابری مستقل همان پرونده ارسال می‌شود. هیچ تلاش مجدد خودکار پس از خطا انجام نمی‌شود.
- پاسخ مدل پیشنهاد کمکی است؛ شاهدها اعتبارسنجی می‌شوند و امتیاز رسمی یا تصمیم انسانی به‌طور خودکار تغییر نمی‌کند.
- رونویسی صوت همچنان به مسیر Groq نیاز دارد؛ DeepSeek در این تغییر برای تحلیل متن است.

## بررسی ساخت
گردش‌کار GitHub Actions در `.github/workflows/version-6-deepseek-checks.yml` کد برنامه را به فضای ساخت Capacitor کپی و `npm run build` را اجرا می‌کند. این بررسی bundle وب را می‌سازد؛ به‌تنهایی تأیید APK نهایی یا آزمون روی گوشی محسوب نمی‌شود.
